Browser-Demo mit echtem Laser-Sound. Die richtige Version läuft im Windows-Terminal.

▸ Installieren

git clone https://github.com/USER/piuu-piuu-3000.git
cd piuu-piuu-3000
python piuu.py

Nur Python 3 nötig, keine Abhängigkeiten. Unter Windows reicht ein Doppelklick auf PIUU.bat.

▸ Tasten

TasteWirkung
Leertaste / Enterschießen
AAutofire an/aus
MTon stumm/laut
NSound-Modus: laser → blaster → chaos
PPause
Q / Strg+Cbeenden + Highscore speichern

▸ Optionen

python piuu.py --auto          # ballert von allein
python piuu.py --mode chaos    # völlig irre Töne
python piuu.py --speed 0.2     # schneller (kleiner = schneller)
python piuu.py --silent        # ohne Ton
python piuu.py --classic       # nur Laser, ohne Gegner
python piuu.py --name Kevin    # Name für den Highscore
python piuu.py --scores        # Hall of Fame anzeigen

▸ Features

  • Echte Töne über winsound.Beep — absteigender Sweep = „piuu"
  • Gegner mit 1–3 HP, Explosions-Animation und *BOOM* / *PENG* / *BLUBB*
  • Wellen alle 5 Kills, mit Fanfare und mehr Punkten
  • Top-10-Highscores in piuu_highscores.json, inkl. 🥇🥈🥉
  • Regenbogenfarben via ANSI, läuft in cmd.exe und Windows Terminal
  • Als PIUU.exe baubar — build_exe.bat doppelklicken
